# Shin-Rorona-no-Atelier-English-Translation-3DS
An attempt to translate Shin Rorona no Atelier for the 3DS in English

## You need a legitimate copy of the game for this patch to work

**This isn't complete at all, it's just a test I've made. A lot of dialogs are translated but display is wrong sometimes and some parts remains japanese.**

## Install : 

Create a folder called **"000400000015CB00"** in the **"luma/title"** folder of your SD card in your 3DS and copy the romfs folder inside of it.
